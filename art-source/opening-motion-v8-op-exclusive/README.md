# Opening motion v8: OP-exclusive short animation

This opening uses newly generated, OP-only action sheets while keeping the
approved in-game character designs as locked model references.

- Delivery: 1080x1920 portrait Full HD
- Playback: 48 fps for exactly 12.000 seconds
- Total video frames: 576 unique frames
- Story: silent ruins -> hero charge -> sacred barrier -> Deatharc attack ->
  Void awakening -> rapid confrontation -> title
- Character animation: six OP-only key poses per featured character, timed at
  48 fps with independent camera, lighting, particle and impact animation
- Featured cast: EX Fox, White Dragon Saint, Deatharc, and the canonical
  black smoke-bodied/orange-marked Void

## Locked character invariants

The face or mask, weapon size, costume patterns, markings, silhouette,
proportions and palette must stay consistent with the game model sheets.
The correct Void is the low quadruped with a smoky body, two wings, orange-gold
lines and a circular orange chest sigil. The unrelated purple upright dragon is
not used.

The generated sheets are intentionally kept as production source. The final
video uses nearest-neighbour enlargement for the character artwork so the
pixel clusters remain sharp rather than becoming blurry interpolated frames.
